`schemas/v1/schema-index.json` is the machine-readable companion. Every row uses the standard schema suite `T-STD`: normal path, boundary values, malformed input, missing-data states, deterministic replay, digest/provenance, and declared failure status. Specialized checks below are additional. Milestone 1 freezes interfaces only; the “component” column names future implementation ownership and does not imply that component exists.

## Coverage rule

A contract is not implemented merely because its schema exists. When its delivery milestone begins, each T-STD class must exercise the component's public producer/consumer seam, and the specialized checks above must be expanded into executable contract tests. Milestone 1 tests prove schema-level coverage and frozen semantics only.
